# Savings Tracker Debugging Exercise

## Purpose

This repository contains a small Python savings tracker with several intentional bugs. The goal is to practice using a debugger to find and understand problems in an existing program.

Rather than simply reading through the code and guessing what is wrong, use the debugger to:

* Run the program and observe its behavior.
* Set breakpoints and step through the code.
* Inspect variables as the program runs.
* Identify where the program's behavior differs from what you expect.
* Fix the bugs and verify that the program works correctly.

## Getting Started

Open the project in PyCharm and run the program. Try using the savings tracker before looking closely at the code. Pay attention to anything that does not behave as expected.

Once you have identified a problem, use the debugger to investigate **why** it is happening.

There are multiple bugs in the program, so don't stop after finding the first one!
